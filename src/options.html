Block reasons

Reasons to choose from

One per line. Anyone blocked with at least one reason (or a note) is never mass-unblocked.

Sync between browsers

Reasons are kept in one secret gist on your GitHub account. Use the same token (a fine-grained token with only the Gists: read and write permission) and passphrase on every device. With a passphrase, the gist is encrypted before it leaves this browser.

Unblock pacing

X starts refusing at about 10 unblocks per 45 s and 50 per 15 min.

Backup

Removing the extension deletes its data, so export now and then.
